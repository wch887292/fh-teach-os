### 项目简介

Teach-OS 是一个教育营销培学 SaaS 平台，面向服装厂老板客群，提供销售端、教师端和管理员端三类角色支持。平台覆盖线索管理、课程交付、转化跟进、智能答疑、培学中心和数据看板等核心功能，并包含数据导出与备份恢复模块。

### 技术栈

- 前端: React + Vite
- 后端: Node.js + Express + TypeScript
- 数据库: SQLite

### 本地启动

- 后端: 进入 apps/server 目录，用 cmd 执行 `JWT_SECRET=teachos-dev-2026-secret npx tsx src/index.ts` 监听 8801 端口
- 前端: 进入 apps/web 目录，用 cmd 执行 `npx vite --port 5173`
